# Technical Decisions

**Projeto:** GymFlow

---

# DT-001

O GymFlow possuirá um único aplicativo.

Após o login, o sistema identificará automaticamente o perfil do usuário.

Professor

- Dashboard
- Alunos
- Exercícios
- Treinos

Aluno

- Meu treino
- Histórico
- Perfil

Esta decisão reduz custos de desenvolvimento, manutenção e publicação.
