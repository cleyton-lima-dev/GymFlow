# Functional Requirements

**Projeto:** GymFlow

---

# RF-001

O sistema deverá permitir que professores realizem login de forma segura.

---

# RF-002

O sistema deverá permitir o cadastro de alunos.

---

# RF-003

O sistema deverá permitir o cadastro de exercícios.

---

# RF-004

O sistema deverá permitir criar treinos personalizados.

---

# RF-005

O sistema deverá permitir organizar treinos por dias da semana.

---

# RF-006

O sistema deverá permitir editar treinos existentes.

---

# RF-007

O sistema deverá permitir que alunos visualizem seus treinos.

---

# RF-008

O sistema deverá permitir que alunos marquem treinos como concluídos.

---

# RF-009

O sistema deverá permitir que alunos consultem seu histórico de treinos.

---

# RF-010

O sistema deverá permitir que professores criem treinos utilizando Modelos de Treino pré-configurados, reduzindo o tempo necessário para montar treinos recorrentes.
