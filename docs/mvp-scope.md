# MVP Scope

**Projeto:** GymFlow

**Versão:** 1.0

**Última atualização:** 06/08/2026

---

# Objetivo do MVP

Entregar uma plataforma funcional que permita substituir o gerenciamento de treinos realizado por fichas impressas ou planilhas, validando o GymFlow em uma academia real.

O MVP será considerado concluído quando um professor conseguir cadastrar um aluno, criar um treino utilizando Modelos de Treino, disponibilizá-lo ao aluno e acompanhar sua execução através do aplicativo.

---

# Funcionalidades do Professor

- Login
- Cadastro de alunos
- Cadastro de exercícios
- Criar Modelos de Treino
- Editar Modelos de Treino
- Criar treino para aluno utilizando um Modelo de Treino
- Editar treino do aluno
- Organizar treino por dias da semana
- Adicionar observações ao treino

---

# Funcionalidades do Aluno

- Login
- Visualizar treino
- Marcar treino como concluído
- Consultar histórico de treinos
- Visualizar dados pessoais

---

# Fora do Escopo do MVP

- Fotos dos exercícios
- Vídeos demonstrativos
- Evolução de carga
- Peso corporal
- Medidas
- Avaliação física
- Chat
- Notificações
- Dashboard
- Relatórios
- QR Code
- Integração com smartwatch

---

# Critérios de Sucesso

O MVP será considerado um sucesso quando:

- O professor conseguir criar um treino em poucos minutos.
- O aluno conseguir consultar seu treino sem auxílio do professor.
- O tempo para montar um treino for menor do que utilizando planilhas.
- A AC PowerGym conseguir utilizar o sistema no dia a dia.
